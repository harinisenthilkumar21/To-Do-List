# ✅ Firebase To-Do List

A simple, clean, and responsive To-Do List web application to help users organize and manage their daily tasks.

## ✨ Features

- **User Authentication:** Sign up and log in using email and password.
- **Task Management:** Add, complete, and delete tasks.
- **Cloud Storage:** Store tasks in Firebase Firestore.
- **Real-Time Sync:** Keep task lists synchronized across devices when signed in to the same account.
- **Responsive Design:** Works on desktop and mobile devices.
- **Secure Data Access:** Firestore security rules restrict users to their own tasks.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Netlify
